## 配布内容

独立監査 r4 合格済みの旧版11ファイルをそのまま配置しました。入口と移行画面には manifest link がなく、JSON の検証・書き出しと新版への案内だけを提供します。静的な旧 manifest は削除します。ほかの既存資材は保持し、ゲームへの入口は移行画面へ置き換えます。

`sw.js` は対象 scope の更新時に skipWaiting / clients.claim するだけです。fetch の横取り、cache 削除、登録解除、localStorage / IndexedDB 変更をしません。所有不明の cache と旧 cache はすべて保持します。変更前 v16 は有効化時に広い cache 削除をするため、復旧目的でもそのまま戻しません。

移行対象は選択中の世界、八作品の保存・自己ベスト・音設定の25キーです。実データやバックアップは repository に含めません。

## 端末での手順

1. 旧版をオンラインで開き、書き出し画面へ更新されたことを確かめます。更新できない場合、サイトデータを消さずに相談してください。
2. 「JSON をファイルに保存」でバックアップし、そのファイルを読み込み欄で検証します。対象・進行・設定が合っていることを確認します。旧版の読み込み欄は検証専用で、保存内容を上書きしません。
3. バックアップの検証前にアンインストールしません。アンインストールする場合は、データを残す選択が実際に表示された場合だけそれを選びます。その選択が出ない場合は旧版を残して相談してください。
4. 新 URL を開き、必要に応じてインストールします。引継ぎ画面で同じ JSON を選び、内容確認・上書きチェック・最終確認の後に読み込みます。
5. 八作品の進行と設定を確認し、バックアップは残します。実機の表示やインストール UI は未確認です。LMF の再インストール案内は全対象の移行後です。

## 復旧と制約

公開前の実装・配布 ZIP と commit を保管します。新版の不具合時も旧版は書き出し可能なまま保ち、修正版を別 deployment として確認してから配布します。旧 v16 SW や、取り込みカプセルを読めない旧ゲームへ機械的に戻しません。アンインストールやサイトデータ削除を復旧手順にしません。

更新されていない端末のオフラインでは古い画面・manifest が残る可能性があります。旧 cache は削除していないため、端末更新までの挙動を強制的には変えません。Chrome / Android の実機インストール UI と本人データ移行は未確認です。

LMF能力DB、ほかのアプリ、Swarm Front、workers.dev は変更対象外です。

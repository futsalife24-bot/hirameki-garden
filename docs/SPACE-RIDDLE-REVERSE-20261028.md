# 反対向きの完成判定を修正（2026-10-28・未公開）

## 判断と原因

本人が第2問の月の画像を示し、「反対向きで揃っても正解にならないのは納得感が薄い。揃わなくするか正解にするか決めて」と依頼。**反対向きも正解にする**と判断した。絵が見えたことをゴールとする遊びなので、見た目の完成と判定を一致させる。

平行投影で奥行きに離したかけらは、正面0だけでなく裏側±πでも鏡像として揃う。旧判定は0に近い角度だけを受理していた。全問の正面解答だけの検証では、この代替解を拾えていなかった。

# ひらめきの庭を端末で引き継ぐ

新URLは https://hirameki-garden.pages.dev/ です。公開と合成データによる検証は完了しています。Android実機・本人のデータ移行は未確認です。

1. 旧アプリまたは https://futsalife24-bot.github.io/hirameki-garden/ を、これまで遊んだ端末・同じブラウザでオンラインで開きます。書き出し画面へ更新されないときは、データを消さずに相談してください。
2. 「JSON をファイルに保存」を押し、ダウンロード先でファイルを確保します。そのファイルを旧画面の読み込み欄へ選び、検証が通ることと、対象・八作品の進行・自己ベスト・音設定を確認します。この旧画面は検証専用なので元データを上書きしません。
3. **バックアップの検証前にはアンインストールしません。** 検証後に旧アプリをアンインストールする場合、データを残す選択が実際に表示された場合だけそれを選びます。選択が出なければ旧アプリを残して相談してください。サイトデータやキャッシュを手動削除しません。
4. 新URLを開いて新版をインストールします。新URLと旧URLは保存場所が別なので、開いただけでは引き継がれません。
5. 新版の引継ぎ画面で同じJSONを選びます。内容を確認し、現在の新版データを置き換えるチェックと最終確認を経て読み込みます。別の進行がすでにある場合は、その新版データも先にJSON保存してください。
6. 八作品の進行と設定を確認します。バックアップは引き続き保管してください。エラー時は元データを消さず、表示された内容を伝えてください。

ブラウザと端末によりインストールUIやデータ保持の選択肢は異なり、実際の表示は未確認です。旧書き出しはオンラインで行ってください。旧未更新端末のオフラインでは古い画面が残ることがあります。

LMF能力DBやほかのアプリにはこの手順を適用しません。LMFの再インストール案内は全対象の移行後です。

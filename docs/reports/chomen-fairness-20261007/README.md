## 方法と限界

275欄の180種類の答えと現ヒントを読んで、日常語／生活・文化知識／教科・用語知識、ヒントによる絞り込み、自然な別名と似ているだけの語を主担当が分類しました。この分類は対象年齢・履修学年・実測難度の判定ではありません。個々の教育課程への対応も調査していません。

コードで数えたものは、文字数、交差位置・相手、交差率、過去の出題面、登録した候補の文字数と交差一致です。小さい「ゃ・ゅ・ょ・っ」も、現ゲームと同じく1マスに数えます。CSVの「全交差時の最大手掛かり」は、**対象語以外の交差語が全部解けた場合**の上限です。実際にその順で解ける保証や、文字から名称を思い出せる保証はありません。

自然言語の別解候補を辞書全体から網羅検索したものではありません。「登録した候補内では別解なし」を「一意性を証明した」に読み替えないでください。語義・教育的判断は主担当レビューであり、別の人による独立監査ではありません。

`chomen.js` の `write()` は、空白を除去・カタカナをひらがなへ変換した後、文字数違いには案内だけを表示し、同文字数の正解文字列以外には書き損じを1加算します。同義語を受理する処理はありません。各欄の判定予測はこのコードの読み取りに基づきます。今回は本番UIへの誤答入力や公開検証を繰り返していません。

## 改訂候補は3件

今回の候補はヒントだけを変え、答え・盤・出題順を維持する案です。まだ採用・実装していません。

| 優先 | 対象と確かめた状態 | 現ヒント → 改訂候補 | 理由と想定別解 | 保存・適用条件 |

| 1 | **21面ヨコ1／たいぎご**。全交差でも `○○○ご`。ごじの1文字目のみと交差 | 「出発」と「到着」のように、意味が反対の語 → **「出発」と「到着」のように、意味が反対の語。漢字では「対」で始まる** | はんいご・はんぎごはどちらも4文字で末尾ごも一致。現ヒント・文字数・全交差で除外できない。漢字の頭を指定して名称を絞る。意味から用語を考える部分は残す | 発展辞書の当該ヒントのみ。21面のentry順・正解4文字・座標・番号を保持。全文字列変更ではなくcだけの差分を確認 |

| 3 | **25面ヨコ2／すじがき**。全交差は `すじ○き`。すいこう・こじ・きごと交差 | 物語の出来事を、順を追って短くまとめたもの → **物語の展開を順に書き表したもの。「筋」で始まる呼び名** | あらすじ・こうがいも4文字の自然な候補。全交差で除外可能なので上の2件とは重大度が違う。開始時の最初のヒントであるため、交差前の妥当な想起を罰しない方向へ限定する | 発展辞書の当該ヒントのみ。25面のentry順・正解・座標・番号を保持。漢字から読みを考える負荷は残り、実プレイで容易すぎないか確認 |

1・2は**別解の存在と判定不一致を確認した問題**、3は**交差で救済できるが先に答える際に曖昧さがある編集上の改善候補**です。選定理由は「全交差でも残る別解」を最優先とし、その次に最初に表示されるヒントの曖昧さを置いたためです。発生頻度やプレイヤーの不満の大きさを測定した順位ではありません。

候補をそのまま採用しても、残した漢字・呼び名の条件からすべての別解が消えることを機械で証明できるわけではありません。実装時は3文を読み直し、変更前の自然な別解を文面から排除できることと、ひらがなの正解が保たれていることを確認します。

## 難しいが維持する判断と、難度の飛び

- **20→21面は負荷の種類が変わる。** 20面は11語中10語が再出、21面は10語すべて初出で、うち8語を教科・用語知識に分類。日常の動物名から定義問題へ移る差はある。ただし「発展・言葉」と表示され、難化自体は本人の依頼であるため、並べ替えの根拠にはしない。
- **23・24面は各10欄中5欄が交差1文字。** とくに24面は「めいだい／はんれい」等の抽象語がまとまるため、名称を知らない場合に止まりやすいという懸念。正答率・停止率は未測定。初出語が多いことと不公平なヒントは別に扱う。
- **28面のすうちょくせんは `○○○○○○ん`。** すいせんを解いても最後のんしか得られない。24面では `○う○○○○ん` であり、救済は弱まる一方、28面では同じ語への再挑戦にもなる。一定の目盛り・一直線という定義は具体的なので、単に長いという理由では変更しない。
- **ぶんすいれい、ちきょう、たいげんどめは残す候補。** それぞれ尾根、陸地、名詞という絞り込みがあり、3・3・2交差で確認もできる。知識負荷はあるが、答えを見てヒントに納得できる形を保っている、という主担当判断。
- **26面のきょうめい／きょうしんは次点の懸念。** 音の文脈では共鳴という呼称が妥当だが、共振も同義の専門語。全交差 `き○う○い` の末尾いで除外できる。既に音という限定があるため、今回の3案より優先を下げた。[日本物理教育学会「物理教育用語集」注8（1983年、PDF24ページ目）](https://www.jstage.jst.go.jp/article/pesj/31/3/31_KJ00005907737/_pdf)を根拠とし、検索結果の取得日を論文発行年とは扱っていない。
- **初面にも生活知識の偏りがある。** 5語中きんかん・すだち・かぼすの3語が柑橘。すだちとかぼすは互いに交差するため、両方知らない人への救済が弱い可能性がある。ただし名産地で語を区別する根拠はあり、本人が詰まると断定しない。
- **既存面は難度が単調に増える設計ではない。** 16面は全8語が再出、17面のみそはヒントのみそ汁に答えが含まれる。休憩や復習になる可能性があり、後半の易しい語を機械的に難化する必要はない。

本人プレイが得られる次の機会には、まず21面の開始、24面の用語群、28面のすうちょくせんについて、「意味が分からない／名前だけ出ない／別の正しい言い方をした」のどれで止まったかと、交差を埋めた後に思い出せたかを短く記録すると判断できます。今回の資料作成にはその回答を必須とせず、救済機能やデータ収集機能は追加していません。

## 保存互換と採用後に必要な検証

今回のファイル追加では本番ファイルを変えていないため、保存・ベスト・配信状態に変更はありません。候補を実装する場合は、保存が `level` と配列の `done` を使っている点に注意します。`done` はentryの順番に対応し、ヒント本文は保存していません。

安全な最小変更は、対象辞書のヒント文字列を変え、既存生成器で生成し直し、出力の `c` 以外が一致することを検証する方法です。生成器の単語候補・キー順・PLAN・乱数消費・盤・答え・entry順は変えないでください。入力の同義語受理はゲーム仕様と交差表示に及ぶ別の変更になるため、今回の候補に含めていません。

採用後に確認する条件は、全28面の順序と各entryの `n,x,y,d,a` の一致、該当箇所以外の `c` の一致、旧途中保存の `done`・miss・ベストの保持、変更後ヒントのスマホ・PCでの全文表示、既存の対象チェックです。書き損じを以前より避けやすくなるため、保存形式が同じでも過去ベストと難しさが完全に同じとは言えません。ベストは勝手に消去しない方針を候補にしています。
